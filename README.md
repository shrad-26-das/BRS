ShelfIQ

ShelfIQ is a simple AI-based Book Recommendation System built using Flask and Machine Learning.

Users can search for books and get similar book recommendations instantly.

-  Top 50 Popular Books
-  Live Search Suggestions
-  Similar Book Recommendations
-  Modern Responsive UI
-  Fast Flask Backend

---

- Python
- Flask
- HTML
- CSS
- Bootstrap
- JavaScript
- NumPy
- Pandas
- Machine Learning
